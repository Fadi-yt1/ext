    Server sources

    Free public servers

    Download public proxy lists and test them. Operators of free proxies are unknown: avoid logging in to sensitive accounts over them. Every server must pass an HTTPS test with certificate validation before it is used.

      Proxio.io

      Use your Proxio API key to load servers from your Proxio account. The key is stored only in this browser.

      Your servers

      Paste HTTP(S) or SOCKS5 proxies, one per line: host:port, host:port:user:pass, user:pass@host:port, or links like socks5://host:1080. Provider snippets work too if the proxy URL is on its own line.

      VLESS, VMess, Trojan and Shadowsocks need the Xray engine of the Tervyn Android app, and Chromium browsers (Chrome, Edge, Brave, Opera) cannot log in to SOCKS5 proxies with a password — use HTTP for authenticated proxies there. Firefox supports both.

        About

        Tervyn VPN for browsers — the desktop companion of the free, account-free Tervyn VPN Android app.

        No accounts, no ads, no telemetry. Everything (settings, servers, history) stays in this browser. The extension protects traffic of this browser only; use the Android app to protect a whole phone.

        Free public proxies are run by unknown third parties. Tervyn only uses servers that pass an HTTPS test with a valid certificate, and websites you open over HTTPS stay end-to-end encrypted, but the proxy operator can see which sites you visit.
